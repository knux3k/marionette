# Porting map: Unity and Unreal to Marionette

GENERATED by `marionette docs` from `crates/marionette-port/data/*.json`. Do not edit by hand; edit the tables. The recipe is `docs/ai/PORTING.md`; look entries up with the `port_map` operation.

Status: `ready` exists now as data (component, action map, file, operation); `script` is a direct call or hook in the TypeScript script API; `rewrite` needs a different code shape (the note says how); `gap` has no equivalent yet; `hazard` breaks determinism and must be rewritten.
