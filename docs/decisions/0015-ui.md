# 0015: Minimal UI as components, built-in bitmap font

Date: 2026-11-11. Status: accepted.

## Decision

- Components in core (`crates/marionette-core/src/ui.rs`): `UiNode` (anchor, pixel offset and
  size, layer) plus one look: `UiRect`, `UiText` or `UiImage`; `UiButton` names an input action.
- The renderer draws UI after the world, in screen pixels (y down), with the sprite shader and a
  pipeline without depth test, batched by texture and sorted by layer then entity id.
- Font: 5x7 glyphs in 6x8 cells drawn for this project (`crates/marionette-assets/src/font.rs`),
  CC0, ASCII upper case; lower case is shown as upper case. Sampled with nearest filtering.

## Why

HUDs and menus need very little. A self-made font avoids any font license question and any
binary file.
