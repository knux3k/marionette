### `AudioListener`

Where sounds are heard from (usually on the camera). Pan follows the listener's right (+X) axis; gain falls off as `1 / (1 + distance)`.

Rust type: `marionette_audio::AudioListener`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `volume` | number | yes | Master gain. |

### `AudioSource`

A sound attached to an entity. `sound` is a WAV/OGG file relative to the scene or a built-in sound (`builtin:beep`, `builtin:jump`, `builtin:thud`).

Rust type: `marionette_audio::AudioSource`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `looping` | boolean | yes |  |
| `sound` | string | yes |  |
| `trigger` | "OnStart" \| "OnCollision" \| "OnJump" \| {OnAction: {action: string}} | yes | When an `AudioSource` plays. |

### `CharacterController`

Walks a kinematic body with input actions: slides along walls, climbs small slopes, stands on ground, jumps, and pushes dynamic bodies. 3D moves in X/Z, 2D in X.

Rust type: `marionette_physics::components::CharacterController`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `gravity` | number | yes | Downward acceleration in m/s². |
| `jump` | string | yes |  |
| `jump_speed` | number | yes | Upward speed when a jump starts. |
| `mass` | number | yes | Mass used when pushing dynamic bodies. |
| `move_forward` | string | yes | Action for back (-1) / forward (+1, toward -Z). Ignored in 2D. |
| `move_x` | string | yes | Action for left (-1) / right (+1). |
| `speed` | number | yes | Horizontal speed in m/s at full input. |
