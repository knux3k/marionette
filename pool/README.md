# Seed CC0 pool

Assets made for the Marionette project and dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Each folder in `assets/` holds
the files and `asset.json` (source and proof). Rebuild byte for byte with
`cargo run -p marionette-pool --example make_seed -- pool`. Layout and rules: decision 0041.
This folder is the seed of the public pool, the repository `knux3k/marionette-assets`;
`pool_verify` checks either.
