| `puppet.glb` | Generated by `crates/marionette-anim/examples/make_puppet.rs` in this repository (rigged character: mesh, skin weights, morph target and the `idle`, `walk`, `wave` clips are computed in code) | CC0 1.0 (public domain) |

No third-party assets are included. Built-in sprite images (`builtin:white`, `builtin:circle`,
`builtin:checker`, `builtin:atlas`, `builtin:font`) and primitive shapes are generated at run time by
`crates/marionette-assets/src/lib.rs`; the 5x7 bitmap font in `crates/marionette-assets/src/font.rs`
was drawn for this project. Built-in sounds (`builtin:beep`, `builtin:jump`, `builtin:thud`) are
synthesized by `crates/marionette-audio/src/lib.rs`. All of these are CC0. The reference images in `examples/reference/` are
renders of the example scenes, also CC0.
